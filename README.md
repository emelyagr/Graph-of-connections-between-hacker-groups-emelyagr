Граф связей хакерских группировок emelyagr — программа для построения графа связей хакерских группировок.

<h2>Использование</h2>

Кода программы в открытом доступе не будет. Разработано в рамках практики защиты субъектов критической информационной инфраструктуры Российской Федерации.

<h2>Преимущества, недостатки и особенности</h2>

Программа представляет собой инструмент для ведения базы индикаторов компрометации (IP-адресов, доменных имён, URL и хэшей), привязанных к хакерским группировкам, с автоматическим объединением повторяющихся сущностей и сохранением истории их появления. 

Она обеспечивает построение интерактивного графа связей с возможностью поиска, фокусировки на выбранной группировке, визуального выделения активных групп и отображения сводной статистики непосредственно на графе. 

Программа поддерживает управление жизненным циклом данных (удаление записей по давности), а также экспорт базы и статистики в форматы Excel, TXT и CSV.

Профит от использования:
1. Упрощение поиска индикаторов (IoCs) по простой базе.
2. Выявление связей между сетевой инфраструктурой хакерских группировок.
3. Выявление использования общего ВПО разными хакерскими группировками.
4. Анализ информации о возможностях и масштабности той или иной группировки на стратегическом уровне.
5. Актуальность индикаторов.
6. Хранение данных, автоформирование и анализ статистики.
