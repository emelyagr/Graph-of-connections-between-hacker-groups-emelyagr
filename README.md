<h2>Преимущества, недостатки и особенности</h2>

.

Преимущества программы:
1. Работоспособность.
2. Быстрая скорость работы программы.
3. Минимально необходимое заимствование сторонних библиотек и строчек кода.
4. Самые лучшие стандарты шифрования и хеширования на данный момент: AES-256 (Fernet) для шифрования, Argon2id для хеширования, PBKDF2 с 600,000 итераций для ключа, соль 32 байта.
5. Мастер-пароль (и все пароли) не хранится — только хеш.
6. Вся база JSON зашифрована целиком (при ошибке мастер-пароля база не запустится). Пароли хешируются с солью.
7. Полностью локальная автономная работа.
8. Весь проект содержится в одном файле формата "*.exe", что позволяет легко его запускать и распространять.
9. Простота в использовании программы.
10. Простота, стиль и читабельность кода.

Недостатки программы:
1. Минимальная функциональность.
2. Отсутствие графического интерфейса (GUI).
